# About

## 관심 분야

- **ML Platform / MLOps:** 실험 재현성, 피처 일관성, 모델 등록, CI/CD/CT
- **LLMOps:** RAG·Agent 평가, 프롬프트/검색 파이프라인 버전 관리, 추적과 관측
- **Cloud Native:** Kubernetes, 컨테이너 기반 서빙, 배포 자동화
- **Industrial AI:** 회귀·시계열 모델링, 데이터 품질, 실무 의사결정
